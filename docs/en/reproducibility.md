# Scientific reproducibility

This document explains how to reproduce, from scratch, the result underpinning the paper — and why it is methodologically honest.

## Running the experiment

```bash
cd recommender
python -m venv venv && venv\Scripts\activate      # Windows (or: source venv/bin/activate)
pip install -r requirements.txt
python -m src.abm.run_simulation
```

Outputs regenerated under `recommender/abm_results/`:

- `statistical_proof.md` — Cohen's d, p-value, the **ablation table**, and the **sanity check**
- `fig_1_ego_depletion.png` — retained cognitive-reserve distribution (Fig. 1)
- `fig_2_kl_divergence.png` — intent × consumption KL divergence (Fig. 2)
- `fig_3_robustness_manifold.png` — robustness manifold (Fig. 3)

These are committed, intentionally generated research artifacts, not stale build output — they are regenerated by the command above whenever the underlying model changes.

## Expected result (N = 1000, T = 60, seed 42)

| Metric | Value |
|---|---|
| Cohen's d (reserve AUC) | **3.25** |
| Cohen's d (bounded R_final/R_max metric) | 3.62 |
| p (Mann-Whitney U) | ≈ 3.8 × 10⁻²⁹⁵ |
| Median KL (baseline → Be-Productive) | 0.87 → 0.21 |

### Ablation — causal attribution

| Configuration | Cohen's d | Median KL (sustained) |
|---|---|---|
| Full model | 3.25 | 0.21 |
| Friction only | 2.57 | 0.87 |
| Min-Norm only | 0.35 | 0.87 |
| Steering only (TS + Hawkes) | ≈ 0 | 0.21 |
| **None (sanity check)** | **≈ 0.02** | 0.87 |

## Why it is fair (confound-free)

The earlier version of the engine baked the result in: it granted recovery (`μ_rest`) only to the treated arm and fixed a 3× lower scroll rate by hand. Here:

- **`μ_rest` is identical across both arms** — recovery is a property of the human, not the algorithm.
- **Load emerges** from the content served (compulsiveness) and from friction; it is not fixed per arm.
- The only difference between arms is the **algorithm's own actions** (min-norm, friction, steering).

The **sanity check** proves this: with every mechanism turned off, the "sustainable" arm degenerates to the baseline and `d ≈ 0`. The effect is not baked into the framework — it is produced by the mechanisms.

## Automated tests

```bash
cd recommender && python -m pytest src/ -q          # 89 tests
```

Includes `src/abm/tests/test_fair_validation.py`, which reproduces `d = 3.25` from a seeded run, verifies the sanity check (`d ≈ 0`), and the ablation ordering. Both **numpy's and the `random` module's** seeds are fixed → strict reproducibility.

## Relationship to the paper

Any figures belonging to the paper itself remain the **published** ones (the paper is not altered) — this repository does not ship copies of them. The honest figures generated by the code live in `recommender/abm_results/`. The 3.25 figure is the same one reported in the paper — now produced by a defensible design.
